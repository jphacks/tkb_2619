## 製品概要

### 背景(製品開発のきっかけ、課題等）

世代・国籍・音楽の好みが違う人とカラオケ・パーティー・ドライブに行くと、相手がどんな音楽を好きなのか分からず、選曲に困ることがよくあります。

| シーン | ギャップ | 起きていること |
| --- | --- | --- |
| 上司とのカラオケ | 世代 | 上司の好きな曲が分からず、歌う曲を選びにくい |
| 留学先でのホームパーティー | 国籍 | 場が盛り上がる曲を流したいが、文化や言語の違いから選曲が難しい |
| サークルでの初ドライブ | 音楽ジャンル | 同乗者の好みが分からず、無難な曲ばかり流してしまう |

好みが合えば距離が縮まるはずなのに、相手の好みが分からないために無難な曲しか流せない。この課題を解決するために「ミューコネ」を作りました。

### 製品説明（具体的な製品の説明）

**共通の好きな曲が、心をつなぐ。** ミューコネは、みんなが知っている曲・聴きたい曲を投票で選ぶ選曲アプリです。

1. 幹事がルームを作り、招待URLを共有する
2. 参加者は Spotify と連携するか、アカウントなしで参加する
3. Spotify でよく聴く曲・手動で追加した曲・AI のおすすめが候補に集まる
4. 候補をスワイプで評価すると、ランキングがリアルタイムで更新される

### 特長

#### 1. 「被る曲」の抽出

各参加者が Spotify で過去1ヶ月によく聴いた曲を取り込み、参加者の間で重複している曲を見つけます。被った人数が多い曲ほど上位に並びます。

#### 2. スワイプ投票とリアルタイムランキング

上=Best(3点) / 右=Better(2点) / 下=So-so(1点) / 左=Nope(0点) の4方向スワイプで評価します。結果は全員の画面にリアルタイムで反映されます。

#### 3. 集団の属性に合わせたAIレコメンド

集まる人たちの性別・ジャンル・国籍・年代（複数選択）と自由入力の条件から、候補を提案します。例えば年代に「20代」と「50代」を選ぶと、両方の世代に届く曲ほど上位になります。

### 解決出来ること

- 選曲にかかる時間を短縮し、知らない曲ばかりが流れる状況を防ぐ
- 世代・国籍・ジャンルが違う相手とも共通の好きな曲が見つかり、仲を深められる

### 注力したこと（こだわり等）

- 選んだ属性のうち何割の人に届くかで曲を評価し、**集団全体に届く曲**を優先するレコメンド
- サーバーを持たず、GitHub Pages からブラウザで直接 Spotify（PKCE認証）・Supabase Realtime・楽曲APIを使う構成
- Supabase が未設定でも、同じブラウザ内のデモモードで全機能が動く

## 開発技術

### 活用した技術

#### フロントエンド

- Next.js + TypeScript
- Tailwind CSS
- Framer Motion（スワイプ操作）

#### バックエンド・データ

- Supabase（PostgreSQL + Realtime）: ルーム・候補・投票の共有とリアルタイム更新
- Spotify Web API: 過去1ヶ月によく聴いた曲の取得（再生回数は取得できないため、順位から重みを計算）
- iTunes Search API: 人気順の曲検索
- MusicBrainz API / Cover Art Archive: アーティストの国・ジャンル、ジャケット画像

#### インフラ

- GitHub Pages / GitHub Actions（main への push で自動デプロイ）

#### デバイス

- スマートフォン
